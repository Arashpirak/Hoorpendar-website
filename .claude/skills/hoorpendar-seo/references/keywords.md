# Keyword map

Search volumes for Persian industrial terms are small and no free tool measures them reliably.
Rank by intent and by what the Search Console "Performance" report shows once the domain is
verified; revisit this list with real query data after a month.

## Spelling variants to cover

Iranian users type these without a half-space and in several spellings. Google treats most
variants as the same query, but the page text should contain the main forms naturally.

| Concept | Variants people type |
|---|---|
| Igniter | جرقه زن، جرقه‌زن، جرقه زن صنعتی، ایگنایتر، اگنایتر، ایگنیتر، igniter |
| Ignition exciter | اکسایتر جرقه، اکسایتر جرقه زن، ایگنیشن اکسایتر، ignition exciter |
| Portable igniter | جرقه زن پرتابل، جرقه زن دستی، جرقه زن قابل حمل |
| Ignition transformer | ترانس جرقه، ترانسفورماتور جرقه، ترانس جرقه مشعل |
| Spark plug and lead | شمع جرقه توربین، کابل جرقه زن، شمع ایگنایتر |
| Burner igniter | جرقه زن مشعل، جرقه زن کوره، جرقه زن بویلر، جرقه زن توربین گازی |
| Battery charger | شارژر باتری، باتری شارژر، شارژر باطری، شارژر باتری صنعتی |
| Rectifier charger | یکسوساز، رکتیفایر، شارژر تریستوری، شارژر باتری تریستوری |
| Uses | شارژر باتری پست برق، شارژر باتری نیروگاه، شارژر باتری دیزل ژنراتور، شارژر باتری استارت توربین، شارژر 110 ولت DC، شارژر 24 ولت |
| Local modifiers | اهواز، خوزستان، آبادان، ماهشهر، مسجدسلیمان، اندیمشک، دزفول، جنوب کشور |
| Commercial intent | قیمت، خرید، سازنده، تولیدکننده، تعمیر، ساخت سفارشی |

«باطری» is a common misspelling; mention it at most once, for example in an FAQ answer, never
in a heading.

## Competitors seen in results (September 2026)

Companies ranking for these terms include makers of turbine exciters and portable igniters and
several diesel-generator charger sellers. Look at the live results before writing a page:
what they cover (types, specs, FAQ, price-on-request) is the minimum the Hoorpendar page must
match, and Hoorpendar's advantage is being the designer and maker with 25 years of installed
units. Do not name competitors on the site.
